Exploratory research on identifying unusual geochemical compositions relative to abiotic reference populations using unsupervised machine learning.

Research Question: How can we recognize geochemical patterns that depart from those expected from nonbiological processes, without assuming in advance which chemical features life must produce?

This project investigates an agnostic approach to biosignature assessment: characterize the natural diversity of abiotic mineral compositions first, then quantify how new samples differ from those reference distributions.

The data was downloaded from GEOROCS (for APATITE geochemcial measurements), and other published literatures for biotic apatites.
All the codes are in 01-notebook.ipynb.

The repository contains:

data/ — Research data and supporting inputs.
notebooks/ — Exploratory analyses in Jupyter notebooks.
outputs/ — Generated analysis products.
utils/ — Supporting Python utilities.
requirements.txt — Python environment dependencies.
